# Results — Trained on the Real MIT-BIH Arrhythmia Database

These are actual results from running the full pipeline against all 48 real
MIT-BIH records (not synthetic/demo data). Generated by:

```bash
python src/preprocessing/build_dataset.py
python src/models/train_baseline.py --model rf
python src/models/train_baseline.py --model svm
python src/models/train_cnn.py --epochs 7 --batch-size 128
python src/models/evaluate.py --model all
```

## Dataset

- **48/48 real MIT-BIH records** processed (100–124, 200–234)
- **109,451 total annotated beats**: 90,593 Normal, 18,858 Arrhythmic
- Stratified 80/20 split (random_state=42): 87,560 training beats, **21,891 held-out test beats** (18,119 Normal, 3,772 Arrhythmic)
- Split is random at the beat level, not patient-level, so beats from the same patient can appear in both train and test sets. A patient-level split would be a stricter evaluation.

## Model comparison

| Model | Trained on | Accuracy | Precision | Recall | F1-score |
|---|---|---|---|---|---|
| Random Forest | Full 87,560 training beats | 97.81% | 93.11% | 94.25% | 93.68% |
| SVM (RBF kernel) | Full 87,560 training beats | 90.64% | 69.53% | 81.31% | 74.96% |
| **1D CNN** | Full 87,560 training beats, 7 epochs | **97.91%** | 92.10% | **96.10%** | **94.06%** |

All three models were evaluated on the same 21,891-beat test set, which none of them saw during training.

## Confusion matrices (Arrhythmic = positive class)

| Model | Normal → Normal | Normal → Arrhythmic (false alarm) | Arrhythmic → Normal (missed) | Arrhythmic → Arrhythmic |
|---|---|---|---|---|
| Random Forest | 17,856 | 263 | 217 | 3,555 |
| 1D CNN | 17,808 | 311 | 147 | 3,625 |

## Per-class breakdown (1D CNN)

```
              precision    recall  f1-score   support
      Normal       0.99      0.98      0.99     18119
  Arrhythmic       0.92      0.96      0.94      3772
    accuracy                           0.98     21891
```

## Interpretation

- The 1D CNN has the highest recall (96.10%), missing 147 of 3,772 real arrhythmic beats. Recall matters most in medical screening, where a missed arrhythmia is worse than a false alarm.
- Random Forest is a strong, interpretable baseline: accuracy within 0.1 point of the CNN and slightly higher precision, but it misses more arrhythmias (217).
- SVM is clearly the weakest even when trained on the full training set. Its gap is not just a data-quantity effect; the RBF-kernel boundary appears less suited to these 5 handcrafted features than tree-based voting.
- The CNN was trained for only 7 epochs, so longer training may improve it further.

## Reproducing

Trained models, processed `.npy` arrays and the raw dataset are not committed because of their size. Download the MIT-BIH database from PhysioNet into `data/mitdb/`, then run the commands above.
